# Smart Grid Load Balancing using ML and GOA

Author: Ansh Tripathi
Date: April 2026

## 1. Project Scope
This work implements a predict-then-optimize smart grid workflow:
1. Forecast hourly load using ML models.
2. Add uncertainty bounds with quantile regression.
3. Add explainability using SHAP.
4. Optimize the dispatch curve using GOA.

The complete pipeline is orchestrated in [main.py](main.py).

## 2. Implemented Data Pipeline
The project uses [dataset/DUQ_hourly.csv](dataset/DUQ_hourly.csv), a real hourly load dataset with 119,068 records.

Implemented preprocessing in [src/preprocessing.py](src/preprocessing.py):
1. Rename columns and sort chronologically.
2. Add 3-tier TOU features: off-peak, shoulder, peak.
3. Add cyclical time features and calendar flags.
4. Add exogenous temperature and squared term.
5. Add lag features: 1, 2, 3, 21, 24, 48, 168.
6. Chronological 80/20 split before rolling/scaler fitting.
7. Compute rolling_mean_24 on train and seed into test.
8. Fit MinMaxScaler on train only.
9. Verify no leakage at lag and rolling boundaries.

Final dimensions:
- Rows after lag cleanup: 118,900
- Train rows: 95,120
- Test rows: 23,780
- Features: 22

## 5. GOA Optimization
Implemented in [src/goa_optimization.py](src/goa_optimization.py) with objective:
F = 0.35 peak_norm + 0.25 par_norm + 0.25 cost_norm + 0.15 var_norm

Current reproducible KPI change using saved best model predictions:
- Peak load: 2819.2358 -> 2472.8055 (12.29% reduction)
- Total cost: 5456722.3582 -> 5042432.4875 (7.59% reduction)
- PAR: 1.7897 -> 1.6950 (5.29% reduction)
- Variance: 85290.8750 -> 63365.1940 (25.71% reduction)

Note: current GOA bounds reduce mean load too, so this is peak shaving with total-energy reduction under the defined constraints.
